# FLIP — исходный проект (прототип, версия 0.2)

Это локальный **интерактивный прототип** Telegram Mini App. Он не подключён к серверу, Telegram-аккаунтам или реальным платежам.

## Запуск в VS Code

1. Распакуйте ZIP и откройте **папку `FLIP`** в VS Code: **File → Open Folder**.
2. Установите расширение **Live Server** от Ritwick Dey, если его ещё нет.
3. Откройте `index.html` и нажмите **Go Live** внизу справа. Или правой кнопкой на `index.html` → **Open with Live Server**.
4. В браузере откроется адрес вида `http://127.0.0.1:5500/`.

Если Live Server не нужен, откройте `index.html` в браузере двойным нажатием. Также можно запустить `python -m http.server 8000` из папки проекта.

## Что изменилось в этой версии

- В интерфейсе, заголовке браузера и документации приложение называется только **FLIP**.
- Блок DROP перестроен по согласованному референсу: большая плашка статуса, квадратная стопка карточек, яркая широкая кнопка и нижняя информационная строка.
- **Все коллекционные карточки — квадратные (1:1)**. Остальные разделы и навигация сохранены.
- Типографика: Golos Text для заголовков, Manrope для интерфейса и Space Grotesk для логотипа. При отсутствии интернета используются системные шрифты.
- Сохраняется локальное состояние демоверсии. Данные из прежнего прототипа читаются автоматически при первом запуске в том же браузере и на том же адресе.

## Демонстрационные возможности

- Пять вкладок: Главная, Коллекция, Обмены, Магазин, Профиль.
- Демодроп с четырёхчасовым таймером и временные карточки-заглушки.
- Демомагазин паков, раздел заданий, уведомления, профиль.
- Локальные данные в `localStorage`; можно сбросить в настройках профиля.

**Важно:** выпадения и баланс пока демонстрационные и не повторяют в точности финальную математику. Реальная игра потребует серверной авторизации, защищённого генератора карточек, атомарных сделок и платежей Telegram Stars. Не используйте локальную демологику в настоящем продукте.

## Как продолжать разработку

На каждом следующем этапе изменяем только согласованный блок и затем отдаём **полный ZIP с исходниками**. Для продолжения работы прикрепляйте последний ZIP, чтобы не потерять внесённые правки.
