# FLIP — проект v0.4 (главный экран — визуальная чистка)

Этот архив содержит полный статический frontend-прототип FLIP. Название для пользователей — только **FLIP**.

## Что изменено в v0.4

- Главный заголовок: «Открой свой дроп.» вместо прежнего слогана.
- Удалены декоративные подписи «Коллекционная игра» и «DROP 001 / FLIP». Описание сокращено.
- При перезарядке скрывается «Открой свою карточку» и текст о том, что карточка уже получена; таймер и статус остаются.
- «Бесплатно» остаётся в спокойном, второстепенном виде.
- В существующем верхнем безопасном отступе Telegram: слабый градиент с медленным зелёным свечением, без новых кнопок.
- Анимированная заставка длится минимум две секунды (до готовности страницы и шрифтов, но не дольше установленного ограничителя), без надписи «Загрузка коллекции».
- Версии ресурсов в адресах обновлены до v0.4.0 для очистки кэша Telegram.

## Сохранено из v0.3

- Экран загрузки с анимированными квадратными карточками. Ждёт загрузку страницы и шрифтов, но не блокирует приложение дольше ~3 секунд.
- Telegram Mini App WebView: инициализация официального bridge, расчёт `safeAreaInset` + `contentSafeAreaInset` с резервным iOS-отступом для старых клиентов. Верхняя панель не должна попадать под кнопку «Закрыть» Telegram.
- Декоративные символы заменяются встроенными SVG вместо системных emoji iOS. Никаких внешних библиотек иконок.
- Версия в URL стилей и скриптов для обновления кэша Telegram.
- Основной DROP и все карты остаются квадратными (1:1); игровая демологика и прогресс сохранены.

## Запуск

В корне репозитория должны лежать `index.html`, `src/`, `docs/`, `README.md`. Запускайте `index.html` через VS Code Live Server. Для проверки на телефоне разместите файлы в подключённом к Vercel GitHub-репозитории.

## Обновление существующего GitHub проекта

Скопируйте **содержимое** папки `FLIP/` из этого архива в корень существующего репозитория `flip_fmsbot` с заменой одноимённых файлов. Не заменяйте и не удаляйте `.git`; `.env` никогда не добавляйте в коммит. Затем сделайте Commit и Push.

## Новые файлы

- `src/scripts/telegram.js` — определяет Telegram, настраивает безопасные отступы и убирает заставку после загрузки;
- `src/scripts/icons.js` — преобразует иконки в SVG, одинаковые на iOS и Android;
- `src/styles/telegram.css` — адаптация отступов и размеров для Telegram.

## Важно

Это frontend-демо: баланс и карточки хранятся в localStorage браузера. Для реальной игры потребуется сервер, каталог, Telegram-авторизация, платежи, транзакции и защита от злоупотреблений.

Если после Push на iPhone осталась старая страница, закройте Mini App и откройте заново. Все наши локальные `src`-файлы теперь имеют query-версию `v=0.4.0` для обновления кэша.
