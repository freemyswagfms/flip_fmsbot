# FLIP v0.6 — каталог Playboi Carti

Это полный **статический демонстрационный frontend** FLIP для Telegram Mini App. В v0.6 добавлены **25 настоящих пользовательских изображений** (5 релизов × 5 утверждённых художественных стилей). Рулетка и длительность раскрытия ~8,9 с сохранены.

## Что появилось

- Новая структура каталога: **артист → релиз / уникальная обложка → редкость** (`src/scripts/catalog.js`). В демонстрационной генерации выбор проходит именно в таком порядке; каждый артист и каждый релиз внутри артиста равновероятны.
- Первый артист: **Playboi Carti**. Загружены `Playboi Carti`, `Die Lit`, `Whole Lotta Red`, `MUSIC`, `In Abundance` (последний пока не подтверждён как официальный релиз; он входит в пользовательский набор изображений).
- Каждая обложка доступна в пяти утверждённых стилях: Common = печатная текстура; Rare = нитки; Epic = мозаика / витраж; Legendary = масляные краски; Mythic = многослойная бумага.
- Все изображения переведены в оптимизированный **WebP 1024×1024**; исходные изображения остаются у автора.
- Анимация раскрывает **настоящую картинку карточки** после прокрутки. Пока крутится рулетка из лёгких рубашек FLIP, изображение победителя заранее загружается.
- «Коллекция» показывает реально полученные в этом демо карточки. Кнопка **«Каталог · демо»** открывает все 25 вариантов для предварительного просмотра; нажатие открывает изображение крупнее и **не означает владение**.
- «Тест рулетки» последовательно показывает пять настоящих стилей + экспериментальный Hidden. Тест не начисляет награды и не меняет перезарядку.
- Hidden остаётся временным демонстрационным изображением без утверждённого художественного стиля. Глитч перенесён со знака вопроса на рамку.
- Алгоритм **soft pity** включён в демоверсию для бесплатных дропов: после 30 неудачных дропов шанс Epic+ растёт за счёт Common / Rare, не выше 50% суммарно; купленные паки pity не затрагивают. Реальная защита от манипуляций потребует сервера.

## Где хранить и как заменять изображения

Полная инструкция: [docs/CATALOG.md](docs/CATALOG.md).

Каждая новая обложка помещается в `src/assets/<id-артиста>/<id-релиза>/<редкость>.webp`.

Например, если не понравился Mythic для *Die Lit*, **достаточно заменить** `src/assets/carti/die-lit/mythic.webp` другим квадратным WebP с тем же названием. Названия в каталоге, стили рамки и анимацию менять не надо.

**Новому релизу** нужна новая папка с пятью файлами и одна запись в `src/scripts/catalog.js`. Новому артисту — новая запись в массиве `artists`. Это пока обычный статический контент, не настоящая база данных.

## Запуск и установка

1. Распакуй ZIP, открой папку `FLIP`.
2. Скопируй **содержимое** `FLIP/` в корень GitHub-репозитория `flip_fmsbot`, с заменой старых файлов.
3. **Не трогай `.git` и `.env`**; секретные файлы никогда не публикуй.
4. GitHub Desktop → Commit → Push origin → дождись деплоя Vercel → открой Telegram Mini App заново.
5. Для локального запуска: VS Code → Live Server → открыть `index.html`.

Важно: не забудь скопировать новую папку `src/assets/` и новый файл `src/scripts/catalog.js` — иначе картинки будут пустыми. Старые активные ссылки на v0.5.x заменены на `v=0.6.0` для обновления кэша.

## Что осталось демонстрационным

- Дроп, баланс F, XP, pity и коллекция пока **сохраняются только в localStorage данного браузера**, не синхронизируются между устройствами и не защищены сервером.
- Реальная авторизация Telegram, серверный генератор выпадений, торговля, проверка задач, магазин за Stars и защищённая база игроков будут добавлены позднее.
- Художественный стиль Hidden и лики пока не подготовлены. Временная Hidden-карточка предназначена для проверки эффекта.
- Разделы обменов и тематических наборов частично являются макетами.
- Архив пока включает **только 5 загруженных изображений релизов Carti**, а не его окончательно проверенную полную дискографию. Официальность отдельных релизов/обложек подтвердим перед расширением каталога.
