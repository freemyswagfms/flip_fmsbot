# FLIP v0.8.3 — закрытая админ-панель

## Как открыть

1. В FLIP через старого тестового Telegram-бота открой «Профиль».
2. Посмотри «Твой Telegram ID» (число).
3. В Vercel для существующего проекта flip-fmsbot открой Settings → Environment Variables.
4. Добавь FLIP_ADMIN_TELEGRAM_ID = твой числовой Telegram ID, среда Production.
5. Нажми Save и сделай новый Production Deploy ПОСЛЕ сохранения переменной.
6. Полностью закрой и снова открой Telegram Mini App.
7. В профиле появится закрытая кнопка «ОТКРЫТЬ АДМИН-ПАНЕЛЬ».

Не используй username в качестве ID. Не отправляй Bot Token, Supabase Secret или другие секреты никому.

## Выдача карточек

- Можно выбрать зарегистрированного игрока через поиск или нажать «СЕБЕ».
- Можно выбрать точный ID варианта из активного каталога и выдать ровно одну копию.
- Режим **Тестовая**: карточка доступна в коллекции, но не засчитывается в рейтинг. Видна метка «ТЕСТ», хранится test_quantity.
- Режим **Рейтинговая**: карточка участвует в предварительном топе, хранится ranked_quantity. Источник выдачи всё равно отражается в закрытом журнале администрации.
- Повтор одного UUID-запроса не добавляет вторую карточку.
- Любая ручная выдача не выдаёт дополнительный XP, F и не изменяет шансы/таймер дропа.
- Игроки без аккаунта FLIP сначала должны войти в приложение хотя бы раз.
- История выдач хранится в Supabase.
- Первичный рейтинг основан на количестве РЕЙТИНГОВЫХ экземпляров. Полноценный сезонный рейтинг позже получит другие критерии.
- Обмены и продажа ещё не реализованы. Прежде чем активировать их, требуется сохранять происхождение каждой копии при передаче/продаже, чтобы тестовая карточка никогда не становилась рейтинговой автоматически.

## Безопасность

Admin API = /api/admin. В каждом запросе сервер снова проверяет Telegram initData по HMAC и сравнивает ID с Production-переменной Vercel. Отсутствующая или неверная переменная полностью отключает доступ. Никаких прямых публичных SQL-запросов из браузера нет: Supabase RPC доступен только service_role.
