# FLIP v0.7 — Личная коллекция

## Структура интерфейса

1. **Коллекция**: статистика открытых вариантов, число экземпляров, список **только реально открытых** артистов.
2. **Артист**: список релизов, по которым у игрока есть хотя бы одна карточка; поиск по названию.
3. **Релиз**: пять слотов `Common / Rare / Epic / Legendary / Mythic`; имеющиеся карточки раскрыты, отсутствующие закрыты значком `?`.
4. **Карточка**: просмотр крупно, художественная техника, редкость, число экземпляров.
5. **История находок**: независимо от текущих экземпляров хранится список когда-либо открытых ID. Предусмотрено для будущих обменов и продажи.
6. **Каталог · демо**: отдельная разработческая галерея всех 25 изображений Carti, **не выдаёт карточки**.

Hidden не относится к пяти обычным слотам. При выпадении временного Hidden в личной коллекции появляется дополнительный **секретный архив**; окончательный стиль Hidden будет выбран позже.

## Логика данных

- `src/scripts/catalog.js`: статический перечень артистов, релизов и стилей.
- `src/scripts/collection.js`: представление каталога и пользовательской коллекции, подсчёт экземпляров, история.
- `src/scripts/app.js`: действия пользователя, локальное состояние, выдача дропа / пака.
- `src/styles/collection.css`: оформление экранов коллекции.
- `localStorage.flip_demo.received`: все полученные экземпляры, включая дубликаты. Старые данные из v0.6 не очищаются.
- `localStorage.flip_demo.discovered`: уникальные ID карточек, когда-либо полученных. При первом запуске v0.7 автоматически пополняется из старого `received`.

Карточки не добавляются от одного лишь просмотра галереи. Продажа и обмены ещё не реализованы, но будущая логика не должна удалять записи из `discovered`.

## Telegram Mini App и двойной тап

- Мобильный Telegram: во время инициализации вызывается `expand()`, затем при поддержке Bot API 8.0 `requestFullscreen()`.
- Если клиент не поддерживает полноэкранный режим, Mini App остаётся развёрнутым BottomSheet, а не падает с ошибкой.
- Верхний отступ вычисляется из `safeAreaInset` и `contentSafeAreaInset`. Старая принудительная константа 88px **убрана для невключённого fullscreen**.
- На десктопной платформе `requestFullscreen()` не вызывается, макет в рамке 420px остаётся прежним.
- `touch-action: manipulation` распространяется на весь интерфейс, включая текстовые и неинтерактивные области коллекции; двойной `dblclick` дополнительно подавляется. Pinch-zoom и прокрутка не блокируются.

Результат на конкретной версии Telegram зависит от нативного клиента и может отличаться от эмуляции в Chrome; необходима проверка на iPhone 12 и desktop Telegram.

## Тестирование

В браузерном стенде проверены: пустая коллекция, загрузка сохранений, подсчёт ×3, переходы «артист → релиз → карточка», поиск, история, 25 изображений галереи, бесплатный дроп, тест рулетки без наград, сброс демо, адаптивность 320/390/1366 px и эмуляция Telegram iOS / desktop API. Данные и владение по-прежнему локальные, реальная база появится позже.
