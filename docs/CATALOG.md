# FLIP — добавление и замена обложек (v0.6)

## Иерархия

1. **Artist** — имя и стабильный идентификатор, например `carti`.
2. **Release / Cover** — один уникальный набор официальных изображений (для демо дополнительно включены изображения, предоставленные автором).
3. **Rarity** — один из пяти вариантов оформления этого изображения.

Одинаковая официальная обложка Deluxe и обычного релиза **не дублируется**. Другую официальную альтернативную обложку добавляем как новую запись релиза/варианта обложки.

## Расположение файлов

```text
src/
  assets/
    carti/
      die-lit/
        common.webp       ← печатная текстура
        rare.webp         ← нитки
        epic.webp         ← мозаика / витраж
        legendary.webp    ← масляные краски
        mythic.webp       ← многослойная бумага
      playboi-carti/
      whole-lotta-red/
      music/
      in-abundance/
  scripts/
    catalog.js            ← список артистов и релизов
```

У каждого из пяти релизов сейчас имеются все пять файлов. Полный состав — 25 WebP.

## Как заменить не понравившийся вариант

Сохрани новый вариант как **квадратный WebP** (желательно 1024×1024, RGB) и замени **ровно один** файл с соответствующим путём. Допустим, нужно обновить бумажный Mythic для MUSIC:

`src/assets/carti/music/mythic.webp`

Ни JS, ни CSS, ни алгоритм выпадения менять не нужно: FLIP продолжит обращаться к тому же пути. После GitHub Desktop → Commit → Push Vercel получит новую версию файлов. Если Telegram показывает старую картинку, полностью закрой Mini App и открой заново; при необходимости проверь кэш клиента.

## Как добавить релиз

1. Создай папку в `src/assets/carti/<release-id>/`.
2. Положи внутрь пять WebP с точными именами `common`, `rare`, `epic`, `legendary`, `mythic`.
3. В `src/scripts/catalog.js` добавь объект `{id:'...',title:'...',year:...}` в `artists[0].releases`.

Редкость задаётся не вручную для артиста, а **случайно** после выбора артиста и релиза. В будущем оригинальные обложки и альтернативные обложки следует структурировать отдельными записями с корректным `release-id`.

## Вероятности (базовые)

- Common — **64,995%** после выделения Hidden из обычных 65%; Rare — 25%; Epic — 8%; Legendary — 1,8%; Mythic — 0,2%; Hidden — 0,005%.
- Hidden пока временный демонстрационный элемент и не является пятой стилизацией конкретной обложки.
- Бесплатные дропы накапливают soft pity после 30 выпадений ниже Epic. Mythic и Legendary не повышаются, добавка идёт в Epic, а Common и Rare уменьшаются пропорционально. Общий шанс Epic+ ограничен 50%.
- Стандартные паки не влияют на pity; в демоверсии выдаются 3 неповторяющиеся разновидности с минимум одной Rare+.

**Важно:** все вычисления пока в браузере, `localStorage` можно изменить руками. В будущей онлайн-версии выдачу должна проверять серверная игровая логика.
