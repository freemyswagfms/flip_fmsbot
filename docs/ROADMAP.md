# FLIP — план поэтапной разработки

## Визуальные правила
- Главная: крупный вводный заголовок + DROP / NEW COLLECTION / TASKS.
- Карточки **строго квадратные (1:1)** везде, включая анимации и превью.
- FLIP — единственное публичное название. Никаких версий в брендинге.
- Тёмная палитра, кислотный лайм и синие акценты. Шрифты: Golos Text, Manrope, Space Grotesk.
- Нижнее меню: Главная / Коллекция / Обмены / Магазин / Профиль.

## Поэтапный план
0. **Главная / визуальная база** — референсный DROP и типографика (эта версия).
1. **Коллекция** — артист → релиз → обложки → редкости; текущие/исторические находки и особые наборы.
2. **Дропы** — приветственные, 4-часовой бесплатный, pity, редкости и настоящий RNG на сервере.
3. **Задания и прогресс** — daily/weekly, XP, уровни, достижения.
4. **Обмены** — три вкладки, встречные предложения, 72 часа, атомарные операции.
5. **Магазин** — стандартные паки, тематические коллекции, лимиты.
6. **Профиль, история, уведомления** — обе витрины, уровни, достижения, сообщения.
7. **Telegram Mini App / backend** — проверка initData, БД, серверная экономика.
8. **Завершение визуальных стилей и баланс** — два оставшихся стиля карточек и итоговые коэффициенты.
9. **Покупка F за Telegram Stars** — размеры и цены пока сознательно отложены.
10. **FLIP Bot** — отдельный этап после основного приложения.

## Правило разработки
Не меняем уже одобренные блоки без явного запроса. Каждое обновление — отдельная проверяемая версия проекта, а не набор разрозненных фрагментов.
