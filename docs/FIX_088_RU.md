# FLIP v0.8.8 — точные счётчики редкостей, блокировка жестов и световая волна

## Исправлен подсчёт карточек

- Каждая кнопка **«ВСЕ / COMMON / RARE / EPIC / LEGENDARY / MYTHIC»** показывает **своё число уникальных вариантов** реально имеющихся у игрока. Например, 14 экземпляров одной Common считаются за **1 уникальную Common**. Дубликаты отображаются на самой карточке отдельно.
- Поиск пересчитывает показатели в каждой категории только среди соответствующих запросу карточек. Выбранная категория скрывает остальные редкости и обновляет «ПОКАЗАНО N ИЗ M».
- Каталог с пятью стартовыми релизами не служит источником количества принадлежащих карточек. Это именно индивидуальные показатели коллекции.

## Просмотр карточки и предотвращение случайного сворачивания

- При открытии просмотра вызывается официальный метод Telegram Mini Apps `Telegram.WebApp.disableVerticalSwipes()` на поддерживаемых клиентах (Bot API 7.7+). При закрытии `enableVerticalSwipes()` вызывается только в том случае, если жесты были активны до открытия. Повторное открытие и закрытие корректно обрабатываются.
- **Важное платформенное ограничение:** даже с `disableVerticalSwipes()` Telegram оставляет возможность свернуть или закрыть приложение свайпом за его **родную шапку**. Нельзя обещать абсолютный запрет сворачивания на всех устройствах.
- Внутри FLIP затемнённый блюреный фон блокирует фоновые кнопки, прокрутку, переходы по вкладкам и фокус клавиатуры. Используется `inert` для элементов приложения с восстановлением прежнего значения при закрытии. На обложке работает `touch-action:none`, чтобы жест был направлен только на её поворот.
- Используется прежний полноэкранный просмотр внутри Mini App, не отдельный внешний сайт.

## Мягкая световая волна

- Заменён центральный радиальный белый блик на **диагональный узкий перелив**, двигающийся по поверхности вместе с поворотом.
- Два тонких полупрозрачных градиентных слоя, без интенсивного пятна по центру пальца. Common отображает самый слабый перелив; Mythic и Hidden — более заметный.
- После отпускания пальца волна вместе с карточкой плавно возвращается в нейтральную позицию; системная настройка `prefers-reduced-motion` сохраняется.

## Технические проверки

- Проверены разные числа редкостей при наличии 14 экземпляров Common и двух разных Rare.
- Проверены блокировка фона во время просмотра, его разблокировка после закрытия, координаты волны, возвращение нейтрального поворота и корректный вызов Telegram методов.
- Нет миграций или изменений инвентаря, CP, XP, списаний и торговых операций.
- Не отключаются жесты закрытия во всех остальных экранах игры. Физический iPhone требует реальной проверки жеста в Mini App после публикации.
