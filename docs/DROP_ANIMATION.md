# FLIP — раскрытие карточки (v0.6)

Тайминг оставлен от v0.5.2: **0,8 с** появления → **5,5 с** прокрутки → **1,2 с** остановки/свечения → **1,4 с** переворота. Итого ~8,9 с. Тап по экрану переводит к следующему этапу. После результата — закрывает.

## Что теперь отображается

- Рулетка состоит из тёмных лёгких рубашек и **не подгружает 25 альбомных обложек**.
- Перед анимацией алгоритм выбирает **артиста → релиз → редкость**.
- Во время прокрутки заранее подгружается **один WebP победителя**.
- После переворота лицевая сторона целиком заполнена настоящим изображением; рамка/свечение создаются CSS, художник не должен встраивать их в саму обложку.
- **Hidden пока демонстрационная заглушка**. Вопросительный знак не глитчит; цифровой сбой применяется только к рамке.
- Режим «ТЕСТ РУЛЕТКИ» показывает пять реальных стилизаций и Hidden по кругу, без наград, XP и изменения таймера.

## Безопасность

Это **прототип**: `src/scripts/app.js` выдаёт карты в `localStorage`. `src/scripts/reveal.js` только показывает уже выбранный результат, поэтому пропуск не меняет выигрыш. Для реальной экономики понадобится сервер, который авторитетно выбирает карточку и обрабатывает начисления.
