# FLIP — анимация открытия бесплатного дропа (v0.5)

## Этапы

| Этап | Ориентир (с) | Поведение |
|---|---:|---|
| intro | 0.52 | Вход в полноэкранную сцену |
| spin | 3.12 | Горизонтальная рулетка из одинаковых тёмных рубашек; переход к целевой позиции с замедлением |
| settle | 0.75 | Остановка в центре, проявление цвета выпавшей редкости |
| flip | 0.90 | Переворот квадратной карты с рубашки на лицевую сторону |
| result | без таймера | Карточка, редкость, артист / релиз, «Продолжить» |

Каждый тап переводит на следующий этап, включая закрытие результата. Клавиша Esc завершает/закрывает сцену. При `prefers-reduced-motion: reduce` сразу показывается результат.

## Цвета

- Common — графитовый `#A7B7AC`
- Rare — зелёный `#BFFF56`
- Epic — фиолетовый `#BD82FF`
- Legendary — золотой `#FFD36A`
- Mythic — красный `#FF626C`
- Hidden — отдельный глитч-эффект без стандартной цветной рубашки

Все карточки строго квадратные 1:1. Для производительности рулетка использует CSS-трансформации и повторяющуюся простую рубашку вместо тяжёлых изображений.

## Безопасность игровых данных

`app.js` сначала генерирует карточку и добавляет её в демонстрационное локальное состояние. После этого `reveal.js` показывает анимацию, не меняя результат и баланс. Скип ничего не начисляет повторно. При перезагрузке во время анимации выданная карточка уже находится в локальной коллекции.

**В продакшене** вся выдача, шансы, учёт pity, ограничения 4 часа и защита от повторных запросов должны выполняться сервером. Демоверсия не заменяет серверную валидацию. Временно используются вымышленные названия и абстрактные изображения релизов.

## Интеграция

- Разметка overlay — `index.html` (`#dropReveal`).
- Стили — `src/styles/reveal.css`.
- Управление анимацией — `src/scripts/reveal.js`.
- Запуск после открытия бесплатного дропа — функция `doDrop()` в `src/scripts/app.js`.
- Telegram safe area — `src/scripts/telegram.js` / `src/styles/telegram.css`.

Для тестирования редкостей на localhost можно открыть `?previewRarity=rare|epic|legendary|mythic|hidden` и сбросить демоданные через настройки профиля. На опубликованном домене этот параметр игнорируется.
