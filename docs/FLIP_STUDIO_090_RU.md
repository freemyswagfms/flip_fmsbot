# FLIP STUDIO v0.9.0 — CMS и каталог

## Реализовано

**Отдельный сайт:** `https://flip-studio-six.vercel.app`. Игровой Telegram Mini App остаётся на `https://flip-fmsbot.vercel.app`.

**Интерфейс STUDIO**
- Адаптивный тёмный dashboard, список артистов, релизы, Music Importer, Artwork Studio, команда и журнал.
- Импорт MusicBrainz (поиск артиста, просмотр дискографии с фильтрацией, выбор записей и импорт в черновики); SoundCloud не используется.
- Редактор пяти основных редкостей и дополнительного Hidden, загрузка индивидуальных обложек, drag-to-crop, масштаб и положение кадра.
- По итогам кадрирования формируются WebP 1024×1024 и превью 384×384; исходный файл сохраняется в закрытом хранилище.
- Пакетная загрузка 2–5 изображений по порядку редкостей и предупреждение о центральной обрезке.
- Черновики и проверка пяти изображений перед публикацией; редактор может подготавливать, но не публиковать.
- Проверка ревизии при сохранении метаданных, чтобы два сотрудника случайно не перезаписали изменения.

**Доступ и безопасность**
- Supabase email OTP / magic link; Owner, Admin, Editor. Авторизация сотрудников через RLS и проверку JWT/роли на сервере.
- Владелец активирует STUDIO одноразовой HMAC-ссылкой, созданной только при проверенной Telegram-сессии в сохранённой админке игрового FLIP. Время действия 5 минут.
- Создание сотрудников и публикации выполняются через защищённый API игры `/api/studio`, использующий уже существующие секретные настройки Vercel. На публичном сервере STUDIO нет secret key.
- Черновые изображения в **private bucket**, опубликованные в отдельном **public read-only bucket**; политика базы запрещает напрямую подделывать ссылки на опубликованные изображения.
- Аудит приглашений, привязки владельца и публикаций.

**Интеграция игры**
- `GET /api/flip` дополнен опубликованным каталогом из Supabase, без изменения механики дропа и торговли.
- Статический Playboi Carti остаётся fallback для демонстрационного режима.
- В игре при входе подгружаются актуальные артисты, релизы и ссылки WebP; ID существующих карточек не меняются.
- Системный Hidden остаётся доступен по старому ID.
- **Выдача карточек / XP / F внутри Mini App сохранена**, существующие эндпойнты `/api/admin` и их логика не заменены.

## Дополнительная ручная настройка Supabase

Чтобы вход по email и приглашения заработали для STUDIO, в **Supabase Dashboard → Authentication → URL Configuration** нужно добавить разрешённый Redirect URL:

`https://flip-studio-six.vercel.app/**`

Также стоит сделать явный `https://flip-studio-six.vercel.app` (если система требует отдельную запись). Для приглашений команды с реальной отправкой писем нужен настроенный SMTP в Supabase Auth. Без SMTP Supabase может ограничивать или блокировать отправку приглашений, особенно на произвольные адреса.

## Деплой

Vercel создал отдельный проект **flip-studio**, но автоматически подключить исходный репозиторий к этому новому проекту через текущий доступ не удалось. Поэтому первый сайт развёрнут вручную из файлов `studio/`; последующие изменения кода студии потребуют нового деплоя либо подключения GitHub через настройки проекта. Добавление *музыкального контента* происходит через базу без деплоя.

## Важные ограничения

- Все изображения 1024×1024 подготавливаются в браузере; браузер не улучшает качество исходника с низким разрешением.
- Первоначальные 5 релизов Playboi Carti остаются игровыми данными. Перенос их в редакционные таблицы как управляемых сущностей должен проводиться отдельно, чтобы не изменять ID игроков.
- Автоматический импорт гарантирует только те релизы, которые MusicBrainz действительно возвращает. Missing, deluxe, альтернативные релизы добавляются вручную.
- Не утверждается, что визуальный QA уже выполнен на физическом iPhone; CI проверяет синтаксис, сборку и серверные инварианты.
