# FLIP — CHANGELOG

## v0.4
- Главный заголовок «Открой свой дроп.», сокращено описание, удалены лишние декоративные подписи.
- Заголовок карточки только для готового дропа; во время перезарядки только статус, кнопка и таймер.
- Более спокойная подпись «Бесплатно».
- Тонкий анимированный зелёный ambient glow в безопасной зоне Telegram; без интерактивных элементов.
- Заставка минимум 2 секунды, надпись загрузки удалена.
- Ресурсы с параметром версии v0.4.0, остальные разделы и игровая демологика сохранены.


## v0.3
- Animated loading splash with delayed font readiness.
- Telegram iOS safe/content-safe area insets and native bridge.
- SVG fallback-free icons for mobile Telegram.
- Cache-busted script/style URLs.
- Original v0.2 home styling retained.

# История изменений FLIP

## Прототип 0.2
- Публичный брендинг упрощён до «FLIP».
- Блок бесплатного дропа переработан по референсу с тремя квадратными картами.
- Установлена единая система шрифтов и размеров для главного экрана.
- Время повторного дропа корректно указано как 4 часа (не раз в сутки).
- Сохранена демонстрационная интерактивность и все пять вкладок.

## Прототип 0.1
- Исходный интерактивный макет главной страницы и заглушек других разделов.
