# FLIP · История обновлений

## v0.9.5 — премиальный магазин, тематические паки, история покупок (2026-11-16)

- Новый адаптивный магазин в стиле FLIP: крупная карточка STANDARD PACK, тематические коллекции, видимый баланс, цена, гарантии и дневной лимит.
- Стандартный пак без изменения экономики: 200 F, три разные карточки, минимум одна Rare+; Soft Pity не действует.
- Два настоящих тематических набора без привязки к конкретным артистам: ARCHIVE (релизы до 2020 года) и NEW ERA (2020+), по 250 F за три карточки. Тематическая фильтрация проверяется Supabase по активным релизам, цены назначаются сервером.
- Вероятности редкостей и Hidden остаются прежними. Оба типа тематических паков делят общий суточный лимит 10 покупок со стандартным; режим владельца «Без лимита» поддерживается.
- Анимированное раскрытие трёх карточек, пропуск анимации, эффекты Mythic и Hidden, режим reduced motion. Награда фактически выдаётся на сервере до запуска визуальной анимации.
- История последних 40 покупок текущего аккаунта, включая старые стандартные паки; можно открыть обложки. День и время — по Москве.
- Рейтинг, Pity, XP/уровни и достижения учитывают тематические паки как настоящие покупки. Подписанный Telegram initData, отсутствие выдач через клиент, защита повторного запроса.
- Покупку F за Stars, паки по отдельным артистам и эксклюзивные платные стили не включали. FLIP STUDIO не затронут.
- SQL: миграция `015_flip_v095_store.sql`.


## v0.8.9 — Mythic Prismatic Foil, Hidden Anomaly и свайп-галерея (2026-11-15)

- Отдельные премиальные оптические материалы для Mythic (радужная фольга) и Hidden (тёмная спектральная аномалия и световые трещины). Эффекты не заменяют и не перекрашивают исходную обложку.
- В крупном просмотре: кнопки перехода, клавиши ← →, счётчик позиции; длинный горизонтальный свайп переключает карточку, короткое движение сохраняет 3D-наклон.
- Контекстные наборы карточек для своей коллекции, релиза, истории и каталога. Дубликаты одного варианта не повторяются.
- Фон остаётся заблокирован и Telegram-свайпы отключены до закрытия большого просмотра, даже при перелистывании.
- Никакой обратной стороны карточки, никаких серверных миграций, новых наград или изменений экономики.
- Подробности: `docs/V089_CARD_OPTICS_AND_SWIPE_RU.md`.


## v0.8.8 — счётчики редкостей и защищённый 3D-просмотр (2026-11-15)

- Исправлены счётчики фильтров коллекции: каждая редкость показывает только свои уникальные варианты, без повторения общего числа карточек; поиск пересчитывает категории.
- Во время крупного просмотра карточки фон затемнён, размыт и неактивен, его прокрутка блокируется.
- При входе в просмотр на поддерживаемых Telegram Mini Apps отключается системный вертикальный свайп сворачивания; при закрытии исходная настройка восстанавливается. Свайп по нативной шапке Telegram заблокировать нельзя.
- Вместо яркого точечного блика добавлена мягкая диагональная волна света с разной интенсивностью в зависимости от редкости.
- Сервер, инвентарь, CP/XP, админка и обмены не изменены.
- Подробно: `docs/FIX_088_RU.md`.

## v0.8.6 — мульти-обмены, встречные предложения и iOS-поля (2026-11-15)

- CP-предпросмотр учитывает весь набор; при принятии сервер передаёт все карточки одной транзакцией, защита от повторных запросов сохраняется.

- Supabase миграции 006 и 007, API и интерфейс обновлены. Подробно: `docs/BUNDLE_TRADES_086_RU.md`.


## v0.8.5 — CP и настоящие обмены (2026-11-14)

- CP рассчитываются из текущего количества рейтинговых карточек (Common 1, Rare 4, Epic 12, Legendary 35, Mythic 90, Hidden 250).
- Дубликаты: 100% / 25% / 10% / 5% / 5% / пять раз по 1% / далее 0%. Лимит 150% на вариант.
- Карточки из админки с режимом «Рейтинговая» полностью учитываются, тестовые исключены.
- Рейтинг топ-50 открывается из профиля. Истинные Telegram ID лидеров не публикуются.
- Серверные обмены 1 на 1: отправка, получение, принятие, отклонение, отмена, 72 часа, актуальный CP-предпросмотр.
- Атомарная передача без тестовых карточек, UUID-идемпотентность, +15 XP с защитой от повторных пар и лимитом пяти в день; +10 XP за новую уникальную карточку.
- Добавлены миграции SQL 004 и 005, приватный API и тесты, документация в `docs/CP_TRADES_085_RU.md`.


## v0.8.4 — поиск карточек, XP/F через админку, иконки iOS (2026-11-14)

- Поиск по административному каталогу на сервере: артист, релиз, редкость, ID; максимум 50 результатов за запрос без выгрузки всех карточек в браузер.
- Три вида выдачи в закрытой админке: карточка (тестовая/рейтинговая), XP и F; каждая операция требует подтверждения.
- XP начисляется с обычным алгоритмом уровней и наград уровня; F добавляются в баланс; выдача не меняет pity и таймер бесплатного дропа.
- Начисления XP/F атомарны, с UUID-идемпотентностью и отдельным журналом. Вход проверяется через Telegram HMAC и серверный ID владельца.
- Динамически построенные элементы админки проходят SVG-замену специальных символов вместо системных эмодзи iOS.
- Изменения в Supabase: `sql/003_flip_v084_admin_rewards.sql`. Перед публикацией кода миграция должна быть применена один раз; прежняя 0.8.3 продолжает работать.
- CP (Collection Points) и публичный рейтинг обсуждаются отдельно и пока НЕ внедрены.

- Идентификатор запроса предотвращает повторное начисление при сетевых сбоях.
- Инвентарь, открытия, баланс, уровень и счётчики синхронизируются с Telegram-аккаунтом.
- Старые локальные демо-данные не импортируются; вне Telegram сохраняется отдельное демо.
- Визуальная рулетка и изображения Carti сохраняются как в v0.7.2.
