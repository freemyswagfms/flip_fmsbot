## FLIP v0.7 — личная коллекция + полноэкранный Telegram

- Новый интерфейс: личная коллекция → открытые артисты → открытые релизы → 5 слотов редкостей; закрытые варианты не показывают обложку.
- Количество экземпляров на карточке ×N; подробный просмотр карточки, поиск по полученным релизам, отдельная история открытий (регистр `discovered`).
- Сохранение и автоматическая миграция прогресса `localStorage.flip_demo` из v0.6; ни новые экраны, ни каталог не выдают лишние карточки.
- Демо-каталог из 25 изображений Carti по-прежнему доступен отдельно от личной коллекции. Баннер нового артиста ведёт в каталог, а не на пустую личную страницу.
- Hidden при реальном выпадении отображается в секретном архиве как временная демо-карточка, без окончательной художественной стилизации.
- Предотвращён двойной тап-zoom на остальных вкладках: CSS `touch-action: manipulation` по всему Mini App, плюс защита от `dblclick`.
- Мобильный Telegram пробует развернуть BottomSheet и перейти в полноценный fullscreen через штатный API, если он поддерживается; без доступного fullscreen сохраняет обычное развёрнутое окно.
- Убран безусловный 88px верхний отступ для обычного BottomSheet. При fullscreen используются safe-area данные Telegram. Telegram Desktop не переводится принудительно в fullscreen.
- Длительность и анимации рулетки, карточные изображения, game demo и стиль главного экрана сохранены.
- Все URL скриптов/стилей обновлены до версии `v=0.7.0`.

## FLIP v0.6 — реальные карточки Carti

- Подключены 25 оптимизированных квадратных WebP (5 релизов × 5 редкостей), статический манифест `src/scripts/catalog.js`.
- Рулетка с прежним таймингом раскрывает настоящие обложки, сохраняя лёгкие рубашки и поэтапный скип.
- Редкости выбираются независимо от популярности артиста: артист → релиз → редкость.
- Коллекция показывает полученные варианты, а новый каталог-демо открывает все 25 изображений для просмотра без начисления.
- Исправлен Hidden: глитч только на рамке, не на вопросительном знаке.
- Реализован soft pity для **локальной демонстрации** бесплатных дропов; реальная система всё ещё требует сервера.
- Баннер «Новая коллекция» показывает Playboi Carti; оптимизация изображений ~85 МБ → ~7 МБ.
- Добавлены `docs/CATALOG.md` и новые пути файлов, версия ресурсов `v=0.6.0`.

## FLIP v0.5.2 — удлинение анимации

- Общая продолжительность полного раскрытия — около 8,9 секунды: вход 0,8 с, рулетка 5,5 с, остановка 1,2 с, переворот 1,4 с.
- Перемещение рулетки теперь длится 5,3 с, переворот карты — 1,16 с.
- Поэтапный скип, результаты, тест без наград и другие игровые механики неизменны.
- Ресурсы обновлены до `v=0.5.2` для корректного обновления в Telegram.

## FLIP v0.5.1 — быстрый тест рулетки

- На главной появилась небольшая кнопка «ТЕСТ РУЛЕТКИ», доступная во время перезарядки дропа.
- Можно повторять рулетку без ограничений. Результат теста не выдаёт карточку и не влияет на баланс, XP, задания или таймер.
- Превью циклически показывает все шесть вариантов редкости, включая Hidden.
- На финальном экране тестовый режим честно помечен «ДЕМО · БЕЗ НАГРАДЫ».
- Сохранён дизайн v0.5 и все остальные функции.
