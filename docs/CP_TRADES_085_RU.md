# FLIP v0.8.5 — CP и обмены (MVP)

## CP (Collection Points)

CP — **не расходуемая валюта**, а вычисляемая оценка текущих рейтинговых карточек. XP и F не конвертируются в CP.

| Редкость | Базовые CP |
|---|---:|
| Common | 1 |
| Rare | 4 |
| Epic | 12 |
| Legendary | 35 |
| Mythic | 90 |
| Hidden | 250 |

Для копий **того же конкретного ID**: 1-я — 100%, 2-я — 25%, 3-я — 10%, 4–5-я — 5% за копию, 6–10-я — 1% за копию, с 11-й — 0%. Максимум за ID = 150% стоимости первой копии. Дробные CP сохраняются до 0,01.

Рейтинговые экземпляры из дропов, паков, обменов и **ручной админ-выдачи в режиме «Рейтинговая» полностью равны**. Тестовые экземпляры исключаются. CP не копятся за прошлые владения: при потере, продаже или обмене карт сумма пересчитывается автоматически.

Рейтинг открывается из профиля. Выводится текущий CP игрока, место среди всех игроков и топ-50. Публичная выдача не передаёт Telegram ID посторонним; для игроков без @username используется стабильный псевдоним.

## Обмены — первый релиз

- Только подтверждённые через Telegram пользователи с существующим серверным аккаунтом.
- Один рейтинговый экземпляр **на один рейтинговый экземпляр**. Тестовые карты и F не участвуют.
- Срок предложения — 72 часа. Исходящие можно отменить; входящие принять или отклонить.
- Никаких резервов при создании предложения. На принятии сервер повторно проверяет текущие запасы обеих сторон, затем **одной транзакцией** меняет владельцев карт, открывает новые находки, рассчитывает CP и XP.
- CP-предпросмотр доступен до отправки и при просмотре входящего предложения. На подтверждении принимающий видит актуальный **серверный** расчёт, а не клиентский.
- Два UUID защищают повторную отправку предложения и повторное принятие. Для пары карт и тех же двух пользователей +15 XP за сделку выдаются только один раз (независимо от направления), максимум пять сделок с +15 XP в сутки на пользователя (сброс по Москве).
- Если обмен открывает карточку впервые в истории игрока, дополнительно даётся 10 XP за новую уникальную находку, один раз в истории аккаунта. Прокачка и награды уровней общие с дропами.

## Защита

API `/api/social` **каждый запрос** проверяет Telegram initData HMAC. ID действующего игрока берётся из проверенной подписи, а не из body. Все изменения выполняются только через RPC с `service_role`. SQL-функции и таблицы закрыты для `anon` и `authenticated`; RLS включён.

## Инструменты и деплой

Схема: `sql/004_flip_v085_cp.sql` и `sql/005_flip_v085_trades.sql`, уже применены к Supabase `flip-game`. Повторно применять не нужно. Frontend содержит `leaderboard.js`, `trades.js`, `social.css`; сервер — `api/social.js`. Переменные Vercel остаются прежними.

Упрощения MVP: нет multi-card предложений, встречных условий в рамках одного оффера и торговли F. Фильтры по сезону, бонусы CP за полный релиз и продвинутый матчмейкинг — последующие этапы, не скрытые возможности этого релиза.
